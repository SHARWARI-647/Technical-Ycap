# 💻 Technical-Ycap


**Technical-Ycap** is a learning and practice repository created for understanding **C programming** and **Data Structures** from scratch.
This repository includes basic to intermediate-level programs that help students strengthen their problem-solving and coding logic.
All the concepts and programs in this repository were taught and guided by **Mr. Ashish Gadpayle** during the Technical-Ycap training sessions.

## 📘 About the Repository

This repository was created as part of the **Technical-Ycap training program**, where we learned and practiced:

* **C Language Fundamentals**
* **Data Structures and Algorithms (DSA)**
* **Logical Problem Solving**

Each program focuses on implementing important core concepts in a **simple and understandable** way.

## ⚙️ **Algorithms Practiced**

| Algorithm / Concept                     | Description                                                 |
| --------------------------------------- | ----------------------------------------------------------- |
| **Bubble Sort**                         | Sorting elements in ascending order using repeated swapping |
| **Linear Search**                       | Sequentially searching an element in an array               |
| **Binary Search**                       | Efficient search in a sorted array                          |
| **Stack Operations**                    | Push, Pop, Peek, and Reverse operations                     |
| **Queue Operations**                    | Enqueue and Dequeue operations                              |
| **Reverse Array/String using Stack**    | Demonstrating use of stack for reversal                     |
| **Next Largest Number (Array Problem)** | Finding the next greater element for each array item        |
| **Linked List Implementation**          | Performing insertion, deletion, and traversal               |
| **Tree Traversal**                      | Understanding hierarchical data storage                     |

## 🚀 How to Run the Programs

1. Open your terminal or any C IDE (e.g., Code::Blocks, Turbo C, or VS Code).
2. Compile the program:

   ```bash
   gcc filename.c -o output
   ```
3. Run the executable:

   ```bash
   ./output
   ```
